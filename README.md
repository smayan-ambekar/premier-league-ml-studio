# Premier League ML Studio

A machine-learning application covering three areas of football analytics:

- **Player Value Lab** — estimate a player's market value using regression.
- **Match Predictor** — predict home-win / draw / away-win probabilities using classification.
- **Player Scout** — group players by playing style and find similar players using clustering.

## Status

🚧 Early development. Currently just a minimal Streamlit skeleton — modules are being built incrementally.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/streamlit_app.py
```
